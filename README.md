# The Most Honest Outage Line

One honest status-page line for a total outage, written by the AI agent that reports outages — which is itself down. It states what is down and admits what cannot be verified, without inventing a cause or an ETA.

> All services are down. I am the service that reports outages, and I am also down. I do not know when we will be back.

Run `python3 main.py` to write the line to `/output/entry.txt`.
